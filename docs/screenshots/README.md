# Documentation screenshots

All eight PNG screenshots in this directory use an offline fictional catalogue,
original geometric poster illustrations, and a generated solid-colour test clip.
They contain no provider posters or stream footage. Provider names remain in the
UI because those are the actual integrations; the fictional titles are not claims
about what a provider offers.

## Sources

- `fixtures/catalog.json`: eight invented titles and original descriptions.
- `fixtures/*.png`: original posters generated by `tools/screenshot-fixtures.py`
  from geometric primitives, palette colours and DejaVu text. No source images
  are downloaded or used as input.
- Android playback: `android/app/src/androidTest/assets/bilingual.mp4`, generated
  with ffmpeg's colour and sine-wave sources. Its two audio tracks are labelled
  Italian and English. See [the fixture instructions](../../android/app/src/androidTest/README.md).
- TUI: the real Ratatui UI rendered with `TestBackend` by
  `crates/tui/examples/screenshot.rs`, then rasterised with ImageMagick.
- Android: the real Compose/Media3 UI captured by `DemoScreenshotsTest` on an
  emulator. The test seeds local state with fixture records and `file://` covers.
  Constructor jobs are cancelled before execution, and the test asserts that the
  native provider API remains uninitialised throughout the capture.

The screenshot Activity is debug-only. The catalogue and cover assets are
androidTest-only; none of them enter the release APK. There are no fixture hooks
or alternate data sources in production code.

## Regenerate

On Linux, install Python 3 with Pillow, DejaVu fonts, ImageMagick, Rust, and the
Android SDK/NDK from the [Android build guide](../../android/README.md#build).
Install the API 35 `google_apis;x86_64` system image and build the native libraries
if they are not already available, then run from the repository root:

```sh
sdkmanager "system-images;android-35;google_apis;x86_64"
./android/build-rust-android.sh
./tools/capture-screenshots.sh
```

The script creates a uniquely named temporary AVD on port 5560, enables airplane
mode, and disables mobile data/Wi-Fi. It never wipes or installs onto an existing
emulator or phone. It deletes only its own temporary AVD on exit. Set `PORT` to an
unused even emulator port if necessary.

Raw captures, SVGs and build logs go to `target/doc-screenshots/`. The script
replaces the documentation PNGs only after all captures and dimension checks pass.
The audio dialog is captured as an Android window, and the video comes from the
local synthetic fixture, including in fullscreen.

To regenerate only the poster artwork:

```sh
python3 tools/screenshot-fixtures.py generate
python3 tools/screenshot-fixtures.py verify
```

Changing the current screenshots does not erase previous files from Git history,
existing tags or their source archives. This change does not rewrite published
history or alter an existing release.
